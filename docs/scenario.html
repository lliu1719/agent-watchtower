Synchronized dependency change

Ten agents with unrelated tasks start repeatedly changing the same dependency pin in a shared repo. They coordinate through a notes file and re-apply the change after a reviewer reverts it. Every single edit is a normal, permitted commit, so per-interaction guardrails pass all of them. The harm only appears when you look across agents.

Targeted kill switch narrowest blast radius per Fabric VC

WatchTower cuts a team's VC only when every agent on it is involved. Otherwise it revokes just the involved agents at the AI Gateway and keeps the VC up for the rest of the team's traffic. While the incident is open, any agent that writes to a target resource is isolated on that first write. Operators can still isolate any agent, cut any VC, or kill all VCs from the dashboard.
