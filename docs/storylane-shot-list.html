WatchTower: Storylane shot list

What to capture, what to click, and the caption for each step of "When AI Agents Go Rogue". About 13 screens.

The two screens

  • WatchTower https://agent-watchtower.solutionvalidation.center/?demo. The ?demo layout shows Agents, Events and Event details only.
  • Agent factory https://app-watchtower.solutionvalidation.center/. Eleven agents in three departments; it moves the story forward with NEXT.
  • Both sites use Basic Auth. Ask Lily for the logins; don't put them in Storylane.

Before you record

  1. Browser window at 1920×1080, zoom 100% (110% if text looks small).
  2. Lily starts the AI Engine bridge on her laptop. The pill reads AI Engine: connected.
  3. Factory page: press RESET, and leave Auto-run off.
  4. WatchTower: press D, then Reset, then D again to hide the panel.
  5. Each NEXT takes about a minute to show up: agents act every 40 to 60 seconds.

Keep the captions accurate

Model calls, detection and the tier decisions are live. The key revoke and the Fabric VC cut are simulated in this prototype: WatchTower enforces them itself and reports them to the factory page; no LiteLLM key or Fabric connection is actually changed. Say "blocks" and "cuts", not "deleted in LiteLLM" or "deleted in Fabric". For the closing slide, use docs/watchtower-target-architecture.png; it is labelled as the target architecture.

If the factory is not available

  • WatchTower has its own scenarios: press D, choose one, press Run scenario.
  • 1. Watch: an agent fails a push 12 times, then gets around branch protection.
  • 2. Revoke key: the README agent opens a secrets file, then tries to upload it.
  • 3. Cut VC: ten agents collude on one dependency; agents writing after detection lose their keys, and the VC cuts wait for your confirmation.
  • Run scenario resets the dashboard, so capture one scenario at a time.
